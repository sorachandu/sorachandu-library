sorachanduの競プロ用C++ライブラリです。
整備に生成AIを利用しているのでご了承ください。

検証の実行方法と公式検証・ローカルテスト・使用例の区分は [verify/README.md](verify/README.md) を参照してください。

## ライブラリのドキュメント

[Pagesの用途別索引](https://sorachandu.github.io/sorachandu-library/)から、
各ライブラリのAPI・計算量・前提条件・使用例・検証範囲を参照できます。

説明の原稿はヘッダと同じ場所の同名Markdown（例: [SCC.md](graph/SCC.md)）です。
ヘッダには使用時に必要な要点を残し、詳しい説明はMarkdownに記載します。
新しいライブラリには対応するMarkdownも追加します。
ドキュメントの生成・確認方法は[執筆ガイド](notes/Documentation.md)を参照してください。
